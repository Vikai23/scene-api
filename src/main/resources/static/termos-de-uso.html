Termos de uso

Scene API · projeto final de Web Services (Senac TSI)

1. O que é esta API

A Scene API é um projeto acadêmico: uma API REST de catálogo musical feita para estudo e demonstração. Ela não é um serviço comercial e pode ser usada livremente para testes, aulas e avaliação.

2. Dados

Os dados ficam em um banco em memória e são apagados toda vez que a aplicação reinicia. O que vem cadastrado é conteúdo de exemplo. Não envie dados pessoais nem informações sensíveis: nada do que for cadastrado é protegido ou guardado de forma permanente.

3. Uso justo

Há um limite de requisições por endereço IP (rate limiting por token bucket), descrito na documentação. Quem passa do limite recebe 429 Too Many Requests e deve esperar o tempo indicado no header Retry-After. Não tente contornar o limite nem sobrecarregar o serviço.

4. Versões

Mudanças que alteram o formato das respostas entram em uma versão nova, escolhida no header X-API-Version. Quem não envia o header continua recebendo a versão 1.

5. Sem garantias

A API é oferecida no estado em que se encontra, sem garantia de disponibilidade, de suporte ou de que os dados estejam corretos. Ela pode mudar ou sair do ar a qualquer momento, sem aviso.

6. Licença e conteúdo

O código-fonte é distribuído sob a licença Apache 2.0. Os nomes de artistas, álbuns e faixas que aparecem nos dados de exemplo pertencem aos seus respectivos donos e são citados apenas como exemplo.
